# Monime Go SDK

> **Status: pre-release.** This unofficial SDK is not yet functional and must not be used for production Monime API calls.

`monime-go` will provide an idiomatic Go client for the versioned [Monime API](https://docs.monime.io/).

## Compatibility

- Go 1.24 or later
- Monime API version `caph.2025-08-23` (planned default)

## Development

Run the standard library checks:

```sh
make check
```

See [MONIME_GO_MASTER_PLAN.md](MONIME_GO_MASTER_PLAN.md) for the approved architecture and phased implementation plan.
